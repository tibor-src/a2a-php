# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## [0.1.0] - 2026-11-20

### Added
- First public release of the A2A PHP SDK targeting specification **v1.0.1** (protocol version `1.0`).
- Client and server for JSON-RPC 2.0 and HTTP+JSON/REST, including streaming (SSE), push notification configs, and Agent Card discovery.
- Pest, PHPStan max, Pint, Rector, and GitHub Actions including an official TCK job.
